# Library Management System

The Library Management System is a software project designed to support the day-to-day operations of a library. It provides functionality for managing book loans, handling reservations, and tracking overdue items and outstanding late fees. The system aims to bring these processes together in a single application, making it easier to keep track of book availability, manage lending activity, and monitor outstanding payments. The project focuses on implementing the core business logic required to handle the interactions between books, borrowers, reservations, and loans.

<br>

The application is built in Java, with Gradle used for build automation and dependency management. Its functionality covers the lending lifecycle, from issuing books and managing reservations to tracking overdue loans and recording delinquent payments associated with late fees. The project provides an opportunity to work with object-oriented design, domain modeling, and the implementation of interconnected business rules in a structured software application.

<br>

To make the application easier to build, package, and run consistently across environments, the system is containerized using Docker. This separates the application from the specifics of the host environment and supports a more reproducible development and deployment workflow. By combining Java, Gradle, and Docker, the project brings together application development, build tooling, and containerization in a practical example of a library administration system.
